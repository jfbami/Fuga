# Mary Gates Hall, 4th floor

| File | What it is |
| --- | --- |
| `landmarks.json` | Signs placed on the plan from the iLounge walk: position, which way they face, how many times seen |
| `route_elevator_430.json` | Elevator lobby (400W) to the 430 Computer Classroom door: 26.7 m, points + spoken steps |
| `route_elevator_416.json` | Elevator lobby (400W) to the 416 iLounge door: 18.6 m |
| `alignment.json` | How the walk was fitted onto the plan, plus the walked path |
| `detections_iLounge-walk.json` | Which sign was seen in which video frame (input to `place_landmarks.py`) |

`floor.json` and `grid.png` are generated from the Space Viewer plan and kept out of git; see `tools/mapping/README.md`.
