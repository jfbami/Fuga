# Mary Gates Hall indoor wayfinding

Start with [PROJECT_LOG.md](PROJECT_LOG.md): the running history, evidence, decisions, limits, and next steps.

## Project layout

- `PROJECT_LOG.md`: living project history and decision register; update after meaningful work or a user decision.
- `localization/`: camera-recognition code, reference-map exports, and reproducible research experiments.
- `capture/`: instructions and a blank manifest for independent regular-phone test photos.
- `../MGH_Master.sqlite`: **the one canonical archive** containing originals, derivatives, annotations, and historical revisions.
- `../MGH_Master_tools.py` and `../MGH_Master_README.md`: archive utility and format guide.

This folder is the organized working/export surface. The existing master stays at its established path; it is not moved, copied, or replaced. New work and revised project notes must also be embedded transactionally in that archive. Recover project assets from its logical `project/` and `scans/` paths if loose exports disappear.

Current milestone: recognize a small portion of the fourth-floor hallway using an ordinary camera, then reach one reviewed entrance. A reconstruction is not a tested localization service or an enabled routing map. No navigation route is enabled yet.
